Anuoluwa Fashion World

A modern and responsive fashion/tailoring website built for **Anuoluwa Fashion World**, a tailoring brand focused on creating elegant and quality outfits while providing excellent customer satisfaction.

##  Live Demo

[anu-oluwa-fash.vercel.app]

**About The Project**

Anuoluwa Fashion World is a frontend web project designed to showcase tailoring services, fashion styles, and allow customers to learn more about the brand and place orders.

The project was built as part of my journey in becoming a **Frontend Web Developer**.

## Features
*  Responsive homepage
*  Fashion and tailoring services
*  Fashion gallery
*  Customer registration/order section
*  Order/contact integration
*  Responsive design for mobile and desktop
*  Modern and clean user interface
*  Customer order submission
